# SGIF — Sistema de Gerenciamento e Inteligência Ferroviária

Protótipo visual do **SGIF (Sistema de Gerenciamento e Inteligência Ferroviária)**, desenvolvido como parte de um projeto acadêmico do **SENAI**.

O projeto tem como proposta apresentar visualmente a interface de um sistema voltado ao **monitoramento de temperatura e vibração em locomotivas e vagões**, servindo como base para uma futura aplicação de coleta, processamento e visualização de dados de telemetria.

> ⚠️ **Status do projeto:** este repositório contém **somente o protótipo visual da aplicação**. As funcionalidades de monitoramento, comunicação com sensores, coleta de dados, processamento e análise ainda não estão implementadas nesta versão.

## 🎯 Sobre o projeto

O SGIF foi concebido para auxiliar no acompanhamento das condições de **locomotivas e vagões** por meio de dados provenientes de sensores.

A proposta envolve a utilização de dados de **temperatura e vibração** para possibilitar o acompanhamento dos equipamentos e, futuramente, auxiliar na identificação de comportamentos anormais e possíveis necessidades de manutenção.

Neste repositório, o foco está exclusivamente na **representação visual e estrutural das telas do sistema**, permitindo demonstrar como a aplicação poderá funcionar futuramente.

## 🖥️ Protótipo

O protótipo apresenta a estrutura visual das principais áreas do sistema, incluindo elementos relacionados a:

* Dashboard de monitoramento;
* Visualização de locomotivas e vagões;
* Informações dos sensores;
* Dados de temperatura;
* Dados de vibração;
* Alertas e anomalias;
* Usuários e níveis de acesso;
* Visualização de informações de monitoramento.

As telas apresentadas são **representações visuais**, não possuindo integração real com sensores ou banco de dados nesta etapa.
